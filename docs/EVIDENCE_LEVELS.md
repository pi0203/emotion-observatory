# 근거 수준 잣대 (2026-11-01, 본인 확인 「맞아」)

이 앱의 화면 문구와 문서가 연구를 말할 때 쓰는 기준이다. 감정·정서 근거 조사(저장소 밖 Aside 세션 문서 「감정·정서 근거 조사 정의서 v0.1」)에서 정했고, 본인이 방향을 확인했다.

## 1. 두 칸을 따로 적는다

### 읽은 수준 (무엇을 읽고 판단했나)
[EVIDENCE_CHAIN.md](EVIDENCE_CHAIN.md)의 표시를 그대로 쓴다: **[원문]** · **[저자본]** · **[초록]** · **[2차 자료]** · **[미확인]**.
- 원문을 우선하고, 못 보면 보류한다.
- 초록이나 2차 자료로 매긴 근거 수준은 「잠정」이다.
- 미확인은 수준을 매기지 않고 「보류」로 둔다.

### 근거 수준 (그 주장이 과학적으로 얼마나 받쳐지나)
| 수준 | 뜻 |
|---|---|
| 단단함 | 여러 독립 연구팀·표본에서 같은 방향. 메타분석이나 다기관 재현이 있다. 정의와 측정이 대체로 합의됨 |
| 있음 | 정의·측정과 독립 재현이 있으나 효과가 작거나 조건(문화·표본·측정)에 따라 달라짐. 또는 상관 연구 중심 |
| 얇음 | 한두 연구, 한 연구팀, 질적·개념 분석, 이론 제안 |
| 흔들림 | 재현 실패나 반론이 더 무겁거나, 원 연구가 철회·정정됨 |
| 없음 | 연구 근거 제시가 없음 |
| (등급 밖) 비유 | 「감정 쓰레기통」처럼 개념이 아니라 비유인 말 |

## 2. 말(단어·표현)은 축을 나눠 적는다
- 사전: 표제어 / 관용구 / 다른 표제어의 용례 / 없음
- 한국어 화자 평정: 쾌·불쾌, 활성화, 범주 합의율. 값은 저장소에 옮기지 않는다([NORMS.md](NORMS.md)).
- 재현: 둘 이상의 독립 표본에서 같은 방향인지
- 심리학 구성개념: 위 근거 수준
- 영어 대응: 1:1 / 부분 / 없음 ([EMOTION_CULTURE.md](EMOTION_CULTURE.md) §7)
- 한 줄 점수로 합치지 않는다. 화면에는 어느 칸도 보이지 않는다.

## 3. 화면 문구 규칙
1. 화면은 연구 결과를 단정하지 않는다. 「일부 연구에서」, 「관련이 보고되었다」 수준으로 쓰고, 이 앱의 효과를 말하지 않는다.
2. 근거 수준이 「흔들림」이나 「없음」인 주장은 화면에 쓰지 않는다(아래 표).
3. 숫자를 쓰면 출처와 읽은 수준을 문서에 남긴다.
4. [tests/evidence-wording.test.ts](../tests/evidence-wording.test.ts)가 화면 문구와 내용 파일에서 단정 낱말(입증, 증명, 확연히, 현저히 등)과 근거가 흔들리거나 없는 숫자(90초, 3:1, 93%)를 막는다.
   - 이 규칙은 감정 대중서 18권 시범에서 연구를 짚는 문장의 73%가 단정형이었다는 관찰에서 왔다([vocab-sources/BOOK_SURVEY_2026_11_01.md](vocab-sources/BOOK_SURVEY_2026_11_01.md)).

## 4. 개념별 근거 수준 (2026-11-01, 대부분 [초록]이라 잠정)

목차에 「감정」·「정서」가 든 대중서들이 장 제목으로 내세우는 개념과, 한국 문화 관련 개념이다. 자세한 근거(인쇄된 수치, DOI)는 저장소 밖 Aside 세션 문서 「감정 개념 근거표 v0」에 있다.

| 개념 | 근거 수준 | 화면에서 쓰지 않는 말 |
|---|---|---|
| 인지적 재평가 (실험 효과) | 단단함 (Webb 외 2012 메타분석) | 「재평가가 가장 좋은 전략」 |
| 표현 억제 | 습관적 억제와 증상의 상관: 있음. 문화에 따라 다름: 있음 | 「억제는 효과가 없다」, 「한국인에게는 억제가 괜찮다」 |
| 반추 | 우울과의 상관: 단단함. 인과: 있음 | 「반추가 우울을 일으킨다」(확정 인과) |
| 감정에 이름 붙이기 | 있음. 「가라앉힌다」는 일반화는 흔들리는 중 (Vlasenko 외 2021 직접 재현 실패) | 「이름만 붙이면 감정이 가라앉는다」 |
| 감정 입자도 | 있음 (부적응 행동과 r = −.15) | 「감정 어휘를 늘리면 정신건강이 좋아진다」 |
| 감정노동 (표면 연기) | 소진과의 연결: 단단함 | 「내면 연기는 건강하다」 |
| 정서지능 | 있음 (지능·성격 위로 0.7~2.3%) | 「IQ보다 EQ가 성공을 좌우한다」 |
| 감정표현불능증 | 있음 (척도 구조 논쟁) | 점수로 개인 판정 |
| 수치심·죄책감 | 있음 | 「죄책감은 좋은 감정, 수치심은 나쁜 감정」 |
| 표현적 글쓰기 | 있음 (평균 r = .075) | 「쓰기만 해도 우울이 낫는다」 |
| 감사 연습 | 있음 (g = 0.19) | 「감사가 우울·불안의 치료법」 |
| 자극 민감성(HSP) | 있음 | 진단명처럼 쓰기 |
| 표정 피드백 | 작은 효과: 있음. 펜 물기: 흔들림 | 「억지 미소로 기분을 바꾼다」 |
| 얼굴로 감정 읽기 | 일대일 대응: 흔들림 (Barrett 외 2019) | 「표정으로 감정을 정확히 안다」 |
| 거절과 몸의 통증 | 「같은 처리」: 흔들림 | 「뇌는 거절과 통증을 구분하지 못한다」 |
| 긍정성 비율 3:1 | 흔들림 (학술지 정정으로 공식 철회 [원문]) | 「긍정:부정 3:1을 넘으면 번영한다」 |
| 메라비언 7-38-55 | 「소통의 93%는 비언어」: 흔들림 | 같은 말 |
| SNS 감정 전염 | 얇음 (d = 0.001~0.02 [원문]) | 「감정 전염이 증명됐다」 |
| 「감정은 90초면 지나간다」 | 없음 | 같은 말 |
| 초민감자(empath) | 없음 | 연구된 유형처럼 소개 |
| 부신피로 | 없음 | 진단처럼 쓰기 |
| 화병 | 척도 있음, 얇음 (권정혜 외 2008 [원문]) | 감정 단어로 쓰기, 진단처럼 쓰기 |
| 억울 | 척도 있음, 얇음 (전예슬·김은하 2021 [원문]) | — |
