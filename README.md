# 감정 관찰실

몸의 상태·상황·의미·감정 개념을 구별해보는 local-first self-monitoring web app의 첫 vertical slice입니다.

현재 구현 범위는 `Landing → Entry gate → Body → Affect → Context → Meaning → Emotion candidate → Outcome → Summary`입니다.

감정 후보는 연구·검토 전의 임시 UI fixture이며, 앱은 사용자의 “진짜 감정”을 추론하거나 진단하지 않습니다.

## Run

```bash
npm install
npm run dev
```
